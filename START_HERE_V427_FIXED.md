# Vika V4.27 — first-launch fix

## Что исправлено

Если Live Tennis API отвечает 403 на `/history/matches`, `run_vika.bat` больше не останавливает запуск. Он сохраняет встроенную историческую базу/модель и продолжает запуск Telegram-бота.

403 History означает только отсутствие History entitlement у ключа API; для первого запуска это не критично.

## Запуск

1. Откройте `.env` и проверьте `LIVETENNISAPI_KEY` и `TELEGRAM_BOT_TOKEN`.
2. Запустите `run_vika.bat`.
3. Если появится сообщение про 403 History — это нормально, Vika продолжит запуск.
4. В Telegram напишите `Привет`.

## Авто-LIVE

После `/start` авто-LIVE включается по умолчанию. Vika мониторит доступные live-матчи и может искать не только победителя, но и game handicap / total games / текущий сет / total sets, если есть достаточные данные и реальные котировки.

## Odds API

`THE_ODDS_API_KEY` оставьте пустым, если платный odds feed пока не подключён. В этом режиме Vika не выдумывает коэффициенты. Для автоматического value-сигнала по нескольким рынкам нужен реальный источник котировок.
