# Vika Auto Mode

После `/start` Vika сама включает авто-мониторинг.

Она:
- понимает обычный русский текст;
- предлагает меню кнопками;
- сама сканирует все доступные LIVE-матчи примерно раз в 45 секунд;
- строит pre-match + live модель;
- отправляет авто-сигнал только при сильном live edge и достаточной уверенности;
- если API не отдаёт live-коэффициент, указывает минимальный коэффициент входа, а не выдумывает цену;
- утром по расписанию отправляет обзор дня.

Команды по-прежнему работают: `/day`, `/live`, `/predict`, `/form`, `/status`.

ВАЖНО: качество авто-сигналов зависит от того, какие live score/stats/odds реально возвращает подключённый API. Бот никогда не должен выдумывать коэффициент.
