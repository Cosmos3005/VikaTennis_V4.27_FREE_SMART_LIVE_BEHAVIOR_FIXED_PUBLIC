# V4.13 Release Notes

V4.13 is the practical-use release. It freezes the verified V4.2 pre-match model and player state through 2025-12-29, keeps the V4.5 live fallback and 100k remainder Monte Carlo, and adds a one-command startup/healthcheck path.

The research pipeline is intentionally separate: we do not claim a trained live XGBoost Champion without real point-by-point history. The official Live Tennis API currently documents BASIC historical tapes from 2023 onward, reconstructed 2013–2022 archive tapes, PRO bulk packages, and ULTRA live/WebSocket features. Check coverage before any historical backtest.
