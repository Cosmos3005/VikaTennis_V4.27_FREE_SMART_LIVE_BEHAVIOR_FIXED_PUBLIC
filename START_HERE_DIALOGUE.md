# Vika V4.27 — Responsive Live + живой диалог

## Что изменилось

- Во время долгого расчёта Vika показывает понятный статус.
- Через 15–20 секунд статус обновляется, чтобы было ясно: расчёт продолжается, бот не завис.
- Telegram остаётся отзывчивым, пока тяжёлый расчёт выполняется в фоне.
- Добавлен редактируемый словарь `vika_dialogue.py` с вариантами естественных ответов.
- Понимаются бытовые приветствия, включая «Ку!», «Приветик», «Добрый вечер».

## Как расширять словарь

Открой `vika_dialogue.py`. Там группы `hello`, `working_day`, `working_live`, `still_working`, `auto_on`, `auto_off`, `unknown`.
Можно добавлять любые русские фразы и варианты ответов.
